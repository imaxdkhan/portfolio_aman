# Multidisciplinary Software Engineering Portfolio

A modern, high-performance personal portfolio website built to showcase a cross-functional background in **Full-Stack Development**, **Data Analytics**, and **Cybersecurity**. 

---

## 🚀 About the Portfolio

This portfolio highlights my end-to-end technical capabilities, featuring production-ready web and mobile applications, automated data processing pipelines, and secure system architectures. It reflects my core philosophy: owning products from system design and database architecture through to production deployment.

---

## 🛠️ Tech Stack

* **Frontend & Web:** React, Next.js, TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS, Bootstrap
* **Mobile Development:** Flutter, Dart
* **Backend & APIs:** Node.js, Express.js, FastAPI, RESTful APIs
* **Databases & Architecture:** PostgreSQL, MySQL, MongoDB, Supabase (Row-Level Security), Firebase/Firestore, SQLite
* **Data Science & ML:** Python, pandas, NumPy, R, scikit-learn, XGBoost, SHAP, Streamlit
* **Cloud & DevOps:** Google Cloud Platform (GCP), Netlify, Render, Git, GitHub, Bash scripting

## 💼 Featured Projects

1. **Nest Hub** *(Next.js, React, Node.js, PostgreSQL, MongoDB, Payment Gateway)*
   * Full-stack smart rental and stay management platform connecting tenants and property owners, featuring secure KYC onboarding, real-time calendars, and hybrid database models.
2. **RepVault** *(Next.js, TypeScript, Supabase, MediaPipe, Tailwind CSS)*
   * AI-assisted personal trainer platform featuring real-time pose estimation form analysis, sub-16ms optimistic UI server actions, and multi-tenant data isolation.
3. **QR Authenticated Voting System** *(Node.js, Express.js, Supabase, face-api.js, PWA)*
   * Secure QR-code and facial-recognition voting authentication platform equipped with conflict detection, OTP verification, JWT session management, brute-force protection, and PWA support.
4. **Customer Churn Prediction System** *(Python, scikit-learn, pandas, XGBoost, SHAP, FastAPI, Streamlit)*
   * End-to-end machine learning pipeline predicting subscription and telecom churn, complete with automated preprocessing, hyper-optimized cross-validation, and SHAP model explainability delivered via an interactive Streamlit dashboard.
