# Personal Portfolio Website — Mohammed Aman Ulla Khan

A clean, modern, single-page portfolio built for **Mohammed Aman Ulla Khan** — Computer Science undergraduate specializing in full-stack development, ETL data pipelines, and database architecture.

This project features a custom design with glassmorphic UI elements, interactive scroll animations, physics-based ambient elements, and subtle custom cursor effects.

---

## 🌟 Key Features

* **Custom UI & Styling:** Modern glassmorphic theme with smooth radial gradients, backdrop filters, and custom CSS variables.
* **Interactive Cursor:** Dual-element fluid custom cursor with context-aware scaling over hoverable targets.
* **Ambient Parallax Droplets:** Floating background visual elements that respond smoothly to mouse movement and page scroll.
* **Section Track Navigation:** Floating vertical navigation sidebar with active section tracking and smooth scrolling.
* **3D Card Tilting:** Interactive tilt effects on featured project cards using real-time mouse tracking.
* **Scroll-Triggered Animations:** Clean reveal animations using native `IntersectionObserver` performance APIs.
* **Fully Responsive:** Adapts gracefully across desktop, tablet, and mobile screens.
